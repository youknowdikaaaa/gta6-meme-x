A GTA 6 meme for make.fun's "Post a GTA 6 meme on X" bounty: after 13 years of waiting, Vice City is finally loading — 99% there. The meme (`meme.png`) is a GTA-style Vice City sunset scene with a loading bar stuck at 99% and make.fun's ghost mascot sitting on it, holding its magenta star coin. The meme is posted on X from a public account with make.fun and the entrant's play code in the post's text; `POST.json` names the post.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `POST.json` to `out/POST.json`, which is all the program has to do — the post itself is the entry, and the house reads it from X.
